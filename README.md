# FSR sensor: Zitpositie_Sensor

Piëzoresistieve (resistieve) dunnefilm druksensoren zijn varistoren (variabele weerstanden) in circuits. </br>

Wanneer de druksensor geen externe druk heeft, bevindt het circuit zich in een hoge impedantietoestand. Wanneer er externe druk op de sensor wordt uitgeoefend, neemt de weerstand af. Met behulp van een multimeter kan de weerstandswaarde direct worden afgelezen.

De weerstandswaarde verandert met de externe druk. De druk & weerstand staan ​​in tegengestelde verhoudingen.
